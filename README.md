## 📖 GitBook Integration
This repository is pre-configured with `SUMMARY.md` and Markdown files for native **GitBook** import.

### How to Sync with GitBook.com:
1. Log in to [GitBook.com](https://www.gitbook.com/).
2. Create a **New Space** or select an existing one.
3. Go to **Space Settings** -> **Integrations** -> **GitHub Sync**.
4. Connect this repository: `ekamartsnsports/TNHD-GitBook-Handbook`.
5. GitBook will automatically parse `SUMMARY.md` and render all chapters under `docs/`.
